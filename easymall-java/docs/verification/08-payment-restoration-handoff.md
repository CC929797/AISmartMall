## 本轮保留的代码修复

- 补充正式通知入口 `POST /api/notify/alipayNotify`，仅此精确入口允许匿名访问，付款结果仍必须验签。
- 支付通知改用支付宝公钥证书及 `rsaCertCheckV1` 验签，核对应用ID，接收成功及交易完成状态。
- 主动查单和通知均携带渠道确认金额；数据库状态更新前核对整组订单金额，重复确认不重复投递发货通知。
- 付款状态更新使用事务；发货队列通知放在提交后，队列故障不会回滚已确认的付款状态。
- 停止从占位的 `project.domain=http://xxx.xxxx.com` 拼接通知地址。需要公网通知时显式配置 `ALIPAY_NOTIFY_URL`；未配置时沿用本地自动查单方式。
- 查单失败保留未确认状态并记录渠道错误码，不将错误响应构造为付款成功。

这些改动尚未提交Git。没有新增数据库表或数据库字段，本轮不需要执行新的SQL。原始 `D:/java/java24/LLstudy/mall/easymall-java` 源码和配置没有修改。
